### 环境发现（新增）

- 🚨 **`git` 走 schannel 正常，但 `curl` 走 schannel 会被吊销检查拦死**：报
  `curl: (35) schannel: ... CRYPT_E_NO_REVOCATION_CHECK (0x80092012)`，`HTTP:000`。
  同一台机器同一时刻 `git -c http.sslBackend=schannel fetch/ls-remote` 却完全正常。
  → **curl 要加 `--ssl-no-revoke`**（实测 HTTP 200）。已写入 MEMORY.md 环境段。
- ⚠️ **git bash 的 `/tmp` 与 Windows 版 Python 不是同一个路径**：`curl -o /tmp/x.json` 写成功，
  但 `python -c "open('/tmp/x.json')"` 报 `No such file or directory`。
  → 要么**直接管道** `curl ... | python -c "import sys,json; json.load(sys.stdin)"`，要么用 Windows 绝对路径。
- `refs/pull/<n>/head` 在 PR **关闭后依然留在远端**（不只合并后保留），所以 `ls-remote` 看到它
  **不代表 PR 还开着** —— 必须查 API 的 `state` / `merged_at` 才能判断。
