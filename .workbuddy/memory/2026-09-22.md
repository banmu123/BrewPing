  从 8,171 字符**重压到 3,655**（是有意压缩，并新增了 5.1.1(iv) 权限合规、`DEVELOPER_DIR`
  等好内容），但**顺手压掉了若干仍活跃的规则**。以 Mac 版为基础，补回 6 组共 ~1,740 字符：
  1. append-only 记忆文件的双机冲突处理流程（备份 → 移开 untracked 同名日志 → checkout → merge → 回填）

  4. Windows：tokio Mutex 不可重入 / HTTP 错误体永远 JSON / `route_layer` 白名单 /
     `lib.rs` crate 级 `allow(dead_code)` 导致「零警告」不可信 + 动态调用盲区 + 厂商配置基线

判据应该是**按规则清单逐条核对语义**，而不是比对字数或行数；
