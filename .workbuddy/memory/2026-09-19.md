# 2026-09-19

## macOS Desktop 1.0.0 发布：DMG 打包 + 公证 + 上传 Release

### 目标
把 Mac 桌面端 1.0.0 打到 GitHub Release v1.0.0，分 Apple Silicon / Intel 两版。

### 真正卡住的地方（两个真 bug，都不是权限问题）
1. **`hdiutil create -format` 只能配 `-srcfolder`/`-srcdevice`** —— 单独用来建空白镜像必报 usage。
   9-17 我据此误判成「/Volumes 不可写 = 缺完全磁盘访问(FDA)」，绕了一大圈。
   ✅ 空白镜像正确写法：`hdiutil create -size 200m -fs HFS+ -volname "X" raw.dmg`（**不带 -format**）。
2. **DMG 本身也要 Developer ID 签名**，只公证不签名 → `spctl` 判
   `rejected / source=no usable signature`。且签名会改内容 → **必须先签名、再公证**。
   顺序：打包 dmg → `codesign --sign ID --timestamp` → `notarytool submit --wait` → `stapler staple`。

### dmgbuild 为何弃用
它把镜像挂到 `/Volumes` 后用 `ditto` 写入；在 FDA 受限环境必失败
（`ditto: ... Operation not permitted`），且**失败时只留下 40KB 空镜像**，极难排查。
✅ 改用：空白镜像 + `hdiutil attach -mountpoint /tmp/xxx`（自定义挂载点，全程不碰 /Volumes）
→ cp app + `ln -s /Applications` → detach → `hdiutil convert -format UDZO`。
代价：无自定义背景图（发布形态仍是 app + Applications 快捷方式，符合需求）。
